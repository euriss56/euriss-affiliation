# EURISS AFFILIATION

Site promotionnel indépendant pour présenter le code EURISS et rediriger les visiteurs vers le lien partenaire officiel.

## Stack
- React 18
- Vite 6
- CSS responsive

## Développement
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
```

Le dossier de production est `dist`. Compatible avec un déploiement Vercel (framework Vite).

## Transparence
Ce site est une page promotionnelle indépendante et n'est pas le site officiel de 1XBET. Les jeux d'argent comportent des risques. Réservé aux majeurs.
